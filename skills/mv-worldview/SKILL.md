# 2단계 · 세계관 (mv-worldview)

목표: 사용자가 상상한 세계를 **구역(zone) 몇 개와 그 사이 포털**로 정리해 `world/world.json` 을 만든다. 3D 모양·색은 다음 단계(mv-concept)에서 고르므로 여기선 **무엇이 어디에 있는지**만 정한다.

## 진행

1. **한 줄 아이디어 받기** — "어떤 곳에서 사람들이 만나면 좋겠어요?" 막막해하면 `reference/presets.md` 의 예시 6개(지하철역, 학교 캠퍼스, 판타지 정원 마을, 우주 정거장, 바닷가 휴양지, 네온 야시장)를 보여 주고 고르게 한다. 섞어도 된다.
2. **세 가지만 묻기** (한 번에 하나씩):
   - 이 세계의 **이름**과 한 줄 소개 (없으면 2~3개 제안)
   - **사람들이 와서 하는 일** (구경·대화·모임·홍보 등) → 구역 성격을 정하는 데 씀
   - **구역 수** (권장 3~5개, 처음엔 작게)
3. **구역 설계안 제시** — 표로 보여 주고 확인받는다:
   | id | 이름 | 형태 | 크기 | 주요 소품 | 연결(포털) |
   - 형태: `open`(야외, 벽 없음) / `room`(실내, 벽·천장 높이)
   - 크기: 가로·세로 20~50 (m). 사람이 많이 모이는 곳은 크게.
   - 소품: 템플릿이 그릴 줄 아는 것만 — `tree bench lamp sign box rock flowers fountain kiosk` (box 는 크기·색 지정 가능, sign/kiosk 는 글씨). 그 밖의 것(예: 우주선, 전철)은 box 조합으로 근사하고, mv-build 단계에서 새 소품 종류를 추가할 수 있다고 알려 준다.
   - 포털: 야외(open)는 가장자리에서 2~3m 안쪽, 실내(room)는 벽 위(가장자리 좌표, 예: 깊이 22면 z=11)에 두면 벽에 문이 뚫린다. **양방향**으로 둔다 (A→B 가 있으면 B→A 도).
4. **world.json 쓰기** — 형식은 키트의 `docs/world-schema.md`. 반드시:
   - `slug`: 영문 소문자·숫자·`-` (배포 주소·채널 이름에 쓰임)
   - `spawn`: 처음 도착할 구역 id
   - 소품·포털 좌표는 구역 크기 안 (가운데가 0,0). 시작 지점 근처(0,4)는 비워 둔다.
5. **검증** — `node <키트>/skills/mv-worldview/reference/validate.mjs world/world.json` 를 돌려 좌표 범위·포털 짝·id 중복을 확인하고, 나온 문제를 고친다.

## 끝나면

- `state.choices.worldview` 에 고른 콘셉트 한 줄, `project.name/slug` 채우기, `steps.worldview.status = "done"`.
- PROGRESS.md 에 구역 표를 그대로 붙여 둔다.
- 다음: `mv-concept` (시안 고르기). 이미 빌드된 프로젝트에서 구역만 바꾼 경우엔 `npm run dev` 화면에서 바로 확인하라고 안내.
